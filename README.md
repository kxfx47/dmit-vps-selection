## Linux VPS推荐时，应该重点看哪些指标？

选择 Linux VPS，不建议只看 CPU 核心数量。

一台适合长期使用的 VPS，通常需要综合考虑以下几个方面：

### 1. CPU 和内存是否匹配实际任务

Linux VPS 常见用途包括：

* WordPress 或其他 CMS 建站

* Docker 容器运行

* Web API 服务

* 小型数据库

* Git 服务

* 开发环境

* 测试环境

如果只是搭建个人博客或轻量服务，1-2 vCore 和 1-2GB 内存通常已经可以满足基础需求。

如果需要运行多个 Docker 容器、数据库或者后台任务，4GB 以上内存会更加舒服。

### 2. 网络线路比峰值带宽更重要

很多 VPS 商家会宣传 1Gbps、10Gbps 端口，但实际体验还取决于：

* 机房位置

* 国际出口质量

* 用户所在地

* 路由情况

* 网络拥塞情况

DMIT 的部分产品重点在网络优化线路，例如香港、洛杉矶和东京节点方案。官方页面显示，不同系列提供不同带宽、流量和线路配置，而不是所有 VPS 使用同一种网络方案。

### 3. SSD 容量不要忽略

运行 Linux 系统本身占用空间并不大，但安装：

* Docker 镜像

* 数据库

* 日志

* 网站文件

* 备份文件

之后，20GB SSD 可能很快变得紧张。

如果计划长期运行服务，80GB 或以上存储通常更容易管理。
